# ЛК корпоративного клиента ИНВИТРО — лендинг

Статическая страница в `landing/` (HTML + CSS + небольшой JS).

## Как открыть

- Локально: откройте `landing/index.html` в браузере
- Через простой сервер:

```bash
python3 -m http.server --directory landing 8000
```

и перейдите на `http://localhost:8000/`.
